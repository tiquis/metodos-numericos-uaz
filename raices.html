1. Clasificación de Métodos

Métodos Cerrados (De Intervalos)

Requieren dos valores iniciales \(x_l\) y \(x_u\) que encierren a la raíz (\(f(x_l) f(x_u) < 0\)). Siempre convergen, pero pueden ser más lentos.

  • Bisección: Divide el intervalo a la mitad rigurosamente. \( x_r = \frac{x_l + x_u}{2} \)
  • Falsa Posición: Traza una recta secante entre los límites para encontrar una intersección más cercana. \( x_r = x_u - \frac{f(x_u)(x_l - x_u)}{f(x_l) - f(x_u)} \)

Métodos Abiertos

No requieren encerrar la raíz, usan fórmulas predictivas. Convergen extremadamente rápido, pero pueden divergir si se eligen malos valores iniciales.

  • Newton-Raphson: Requiere la derivada exacta y un punto inicial \(x_0\). \( x_{i+1} = x_i - \frac{f(x_i)}{f'(x_i)} \)
  • Secante: Aproxima la derivada usando dos puntos iniciales (\(x_{-1}, x_0\)). \( x_{i+1} = x_i - \frac{f(x_i)(x_{i-1} - x_i)}{f(x_{i-1}) - f(x_i)} \)

import math

def biseccion(f, xl, xu, tol=1e-6, max_iter=50):
    if f(xl) * f(xu) >= 0:
        raise ValueError("El intervalo no encierra una raíz.")
    xr = xl
    for i in range(max_iter):
        xr_old = xr
        xr = (xl + xu) / 2
        ea = 100.0 if i == 0 else abs((xr - xr_old) / xr) * 100
        
        test = f(xl) * f(xr)
        if test < 0: xu = xr
        elif test > 0: xl = xr
        else: ea = 0.0
            
        if ea < tol: break
    return xr

def falsa_posicion(f, xl, xu, tol=1e-6, max_iter=50):
    if f(xl) * f(xu) >= 0:
        raise ValueError("El intervalo no encierra una raíz.")
    xr = xl
    for i in range(max_iter):
        xr_old = xr
        # Fórmula de la recta secante interpolada
        xr = xu - (f(xu) * (xl - xu)) / (f(xl) - f(xu))
        ea = 100.0 if i == 0 else abs((xr - xr_old) / xr) * 100
        
        test = f(xl) * f(xr)
        if test < 0: xu = xr
        elif test > 0: xl = xr
        else: ea = 0.0
            
        if ea < tol: break
    return xr

def newton_raphson(f, df, x0, tol=1e-6, max_iter=50):
    xi = x0
    for i in range(max_iter):
        if df(xi) == 0:
            raise ZeroDivisionError("Derivada cero.")
        xi_next = xi - f(xi) / df(xi)
        ea = abs((xi_next - xi) / xi_next) * 100
        xi = xi_next
        if ea < tol: break
    return xi

def secante(f, x_prev, x_curr, tol=1e-6, max_iter=50):
    for i in range(max_iter):
        f_prev = f(x_prev)
        f_curr = f(x_curr)
        if f_prev - f_curr == 0:
            raise ZeroDivisionError("División por cero en Secante.")
            
        # Aproximación de la derivada mediante diferencias finitas
        x_next = x_curr - (f_curr * (x_prev - x_curr)) / (f_prev - f_curr)
        ea = abs((x_next - x_curr) / x_next) * 100
        
        x_prev = x_curr
        x_curr = x_next
        if ea < tol: break
    return x_curr
