1. Fundamento Teórico

Regla de Simpson 1/3

Sustituye la función objetivo por polinomios de segundo grado (parábolas). Requiere 3 puntos para definir cada parábola, por lo que el número de segmentos \(n\) debe ser siempre par.

$$ I \approx \frac{h}{3} \left[ f(x_0) + 4\sum_{i=1, 3, 5}^{n-1} f(x_i) + 2\sum_{j=2, 4, 6}^{n-2} f(x_j) + f(x_n) \right] $$

Regla de Simpson 3/8

Utiliza polinomios de tercer grado (cúbicos) para la interpolación. Como requiere 4 puntos por curva, el número de segmentos \(n\) debe ser múltiplo de 3.

$$ I \approx \frac{3h}{8} \left[ f(x_0) + 3\sum_{i \neq 3k} f(x_i) + 2\sum_{j = 3k} f(x_j) + f(x_n) \right] $$

3. Implementación Vectorizada en Python

A continuación, se presentan ambas reglas implementadas en Python aprovechando las bondades del slicing de arreglos en numpy. Esta técnica evita usar bucles pesados, logrando una ejecución matemática mucho más rápida.

simpson_methods.py 
import numpy as np

def simpson_13_multiple(f, a, b, n):
    """Implementación de la Regla de Simpson 1/3 de segmentos múltiples."""
    if n % 2 != 0:
        raise ValueError("Para Simpson 1/3, el número de segmentos (n) debe ser par.")
    
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    
    # y[1:-1:2] toma los índices impares, y[2:-2:2] toma los pares
    suma = y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-2:2])
    return (h / 3) * suma

def simpson_38_multiple(f, a, b, n):
    """Implementación de la Regla de Simpson 3/8 de segmentos múltiples."""
    if n % 3 != 0:
        raise ValueError("Para Simpson 3/8, el número de segmentos (n) debe ser múltiplo de 3.")
        
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    
    # Máscara booleana para encontrar los índices que NO son múltiplos de 3
    indices = np.arange(1, n)
    multiplos_de_3 = (indices % 3 == 0)
    no_multiplos = ~multiplos_de_3
    
    suma = y[0] + y[-1] + 3 * np.sum(y[indices[no_multiplos]]) + 2 * np.sum(y[indices[multiplos_de_3]])
    return (3 * h / 8) * suma

# --- Ejemplo de uso ---
if __name__ == "__main__":
    # Definimos f(x) usando numpy para soporte vectorial
    f = lambda x: 10 + 2 * np.sin(x) * np.exp(0.2 * x)
    
    a, b = 0.0, 8.0
    
    res_13 = simpson_13_multiple(f, a, b, 6)   # n=6 (es par)
    res_38 = simpson_38_multiple(f, a, b, 6)   # n=6 (es múltiplo de 3)
    
    print(f"Área (Simpson 1/3) : {res_13:.5f}")
    print(f"Área (Simpson 3/8) : {res_38:.5f}")
