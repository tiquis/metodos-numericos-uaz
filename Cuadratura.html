1. El Poder de los Puntos Óptimos

A diferencia de los métodos de Newton-Cotes que usan puntos separados a distancias iguales, la Cuadratura de Gauss optimiza tanto los pesos (\(w_i\)) como la posición de los puntos (\(t_i\)) para minimizar el error.

Un polinomio de grado \(2n - 1\) puede ser integrado de manera exacta utilizando tan solo \(n\) puntos. Las fórmulas estándar se definen para el intervalo \([-1, 1]\):

$$\int_{-1}^{1} g(t) dt \approx \sum_{i=1}^{n} w_i g(t_i)$$

Transformación de Coordenadas

Para integrar en un intervalo arbitrario \([a, b]\), debemos aplicar un cambio de variable desde el dominio \(t \in [-1, 1]\) hacia \(x \in [a, b]\):

$$x = \frac{b-a}{2}t + \frac{b+a}{2} \quad \text{y} \quad dx = \frac{b-a}{2}dt$$

Fórmula Final de Integración:

$$\int_{a}^{b} f(x) dx \approx \frac{b-a}{2} \sum_{i=1}^{n} w_i \cdot f\left( \frac{b-a}{2}t_i + \frac{b+a}{2} \right)$$

3. Implementación Vectorizada en Python

En Python, podemos usar numpy para manejar los arreglos de pesos (w) y raíces (t). Además, mostramos cómo usar la librería estándar scipy.integrate para obtener las raíces de Legendre automáticamente para cualquier valor de \(n\).

cuadratura_gaussiana.py 
import numpy as np
from numpy.polynomial.legendre import leggauss

def cuadratura_gaussiana(f, a, b, n):
    """
    Aproxima la integral de f(x) en [a, b] usando Cuadratura de Gauss-Legendre.
    
    Parámetros:
    f : función a integrar
    a : límite inferior
    b : límite superior
    n : número de puntos de integración
    """
    # 1. Obtener raíces (t) y pesos (w) de los polinomios de Legendre para [-1, 1]
    t, w = leggauss(n)
    
    # 2. Transformar las raíces (t) del dominio [-1, 1] al dominio [a, b]
    x = 0.5 * (b - a) * t + 0.5 * (b + a)
    
    # 3. Evaluar la función en los puntos transformados
    fx = f(x)
    
    # 4. Multiplicar por pesos, sumar, y ajustar por el diferencial dx
    integral = 0.5 * (b - a) * np.sum(w * fx)
    
    return integral, x, w

# --- Ejemplo de Uso ---
if __name__ == "__main__":
    # Polinomio de grado 5 (Chapra)
    f = lambda x: 0.2 + 25*x - 200*x**2 + 675*x**3 - 900*x**4 + 400*x**5
    a, b = 0.0, 0.8
    
    # Probando con 3 puntos (debería ser exacto para un polinomio de grado 5)
    n_puntos = 3
    resultado, nodos_evaluados, pesos = cuadratura_gaussiana(f, a, b, n_puntos)
    
    print(f"Nodos de evaluación transformados: {nodos_evaluados}")
    print(f"Pesos de Legendre: {pesos}")
    print(f"Área Calculada (I): {resultado:.7f}")
