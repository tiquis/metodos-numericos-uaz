Integración de Romberg

Suite de Laboratorios Interactivos | Extrapolación de Richardson

1. Fundamento Teórico

La integración de Romberg es una técnica que evalúa el integrando en puntos equiespaciados y aplica la extrapolación de Richardson repetidamente sobre los resultados de la regla del trapecio para obtener estimaciones con errores de truncamiento muy pequeños.

La primera columna \(R_{k,0}\) se calcula usando la regla del Trapecio de segmentos múltiples, donde el número de segmentos se duplica en cada iteración (\(n = 2^k\)).

Fórmula de Extrapolación:

$$ R_{k, j} = R_{k, j-1} + \frac{R_{k, j-1} - R_{k-1, j-1}}{4^j - 1} $$

Donde:
• \(k\) es el nivel (filas), \(j\) es el nivel de extrapolación (columnas).
• \(j=1\) mejora la precisión a \(O(h^4)\) (equivalente a Simpson 1/3).
• \(j=2\) mejora la precisión a \(O(h^6)\) (Regla de Boole), y así sucesivamente.

3. Implementación en Python

La implementación genera una matriz triangular inferior. Observa cómo la primera columna (índice 0) invoca la regla del trapecio, y los bucles anidados resuelven las extrapolaciones aprovechando los cálculos previos.

romberg.py 
import numpy as np

def regla_trapecio_multiple(f, a, b, n):
    """Calcula el trapecio múltiple para n segmentos."""
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    return (h / 2) * (y[0] + 2 * np.sum(y[1:-1]) + y[-1])

def integracion_romberg(f, a, b, niveles):
    """
    Aproxima la integral usando el método de Romberg.
    
    Parámetros:
    f       : función a integrar
    a, b    : límites de integración
    niveles : número de refinamientos (filas de la tabla)
    
    Retorna:
    R       : Matriz de Romberg (triangular inferior)
    """
    # Inicializar la matriz R con ceros
    R = np.zeros((niveles, niveles))
    
    # Nivel 0 (Trapecio simple)
    R[0, 0] = regla_trapecio_multiple(f, a, b, 1)
    
    for k in range(1, niveles):
        # 1. Trapecio con 2^k segmentos (Columna 0)
        n = 2**k
        R[k, 0] = regla_trapecio_multiple(f, a, b, n)
        
        # 2. Extrapolación de Richardson (Columnas posteriores)
        for j in range(1, k + 1):
            R[k, j] = R[k, j-1] + (R[k, j-1] - R[k-1, j-1]) / ((4**j) - 1)
            
    return R

# --- Ejemplo de uso ---
if __name__ == "__main__":
    f = lambda x: 0.2 + 25*x - 200*x**2 + 675*x**3 - 900*x**4 + 400*x**5
    a, b = 0.0, 0.8
    niveles_k = 4
    
    tabla_R = integracion_romberg(f, a, b, niveles_k)
    
    print("Tabla de Romberg resultante:")
    for fila in tabla_R:
        valores_validos = [val for val in fila if val != 0]
        formateados = [f"{v:10.6f}" for v in valores_validos]
        print(" | ".join(formateados))
        
    print(f"\nMejor estimación: {tabla_R[-1, -1]:.6f}")
