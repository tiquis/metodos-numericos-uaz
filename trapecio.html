Regla del Trapecio Simple y de Segmentos Múltiples

1. Fundamento Teórico

Regla del Trapecio Simple

La regla del trapecio es la primera de las fórmulas cerradas de integración de Newton-Cotes. Corresponde al caso donde el polinomio interpolador es de primer grado (una línea recta).

$$ I \approx (b - a) \frac{f(a) + f(b)}{2} $$

Regla de Segmentos Múltiples

Para reducir el error de truncamiento, dividimos el intervalo de integración \([a, b]\) en \(n\) segmentos de igual ancho \(h = \frac{b - a}{n}\). Aplicamos la regla simple a cada segmento y sumamos.

$$ I \approx \frac{h}{2} \left[ f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n) \right] $$

3. Implementación en Python

Para la implementación computacional, aprovecharemos el poder del cálculo vectorizado utilizando la biblioteca numpy. Esto evita bucles for innecesarios, haciendo el código más limpio y eficiente, una práctica esencial en la ingeniería de software científico.

trapecio.py 
import numpy as np

def f(x):
    """
    Función objetivo a integrar. 
    Modifica el retorno con la ecuación deseada.
    """
    return -0.2 * x**2 + 2 * x + 3

def regla_trapecio_multiple(funcion, a, b, n):
    """
    Aproxima la integral definida de una función usando la regla del trapecio compuesta.
    
    Parámetros:
    funcion : objeto de función de Python
    a       : Límite inferior de integración (float)
    b       : Límite superior de integración (float)
    n       : Número de segmentos o subintervalos (int)
    
    Retorna:
    float   : Valor aproximado de la integral
    """
    # 1. Calculamos el ancho de cada segmento (h)
    h = (b - a) / n
    
    # 2. Generamos un arreglo con los puntos x evaluados (desde x_0 hasta x_n)
    x = np.linspace(a, b, n + 1)
    
    # 3. Evaluamos la función en todos los puntos x al mismo tiempo (vectorización)
    y = funcion(x)
    
    # 4. Aplicamos la fórmula matemática: 
    #    I = (h/2) * [f(x_0) + 2*sumatoria(f(x_i)) + f(x_n)]
    
    suma_extremos = y[0] + y[-1]
    suma_interior = np.sum(y[1:-1])  # Ignora el primero y el último
    
    integral = (h / 2) * (suma_extremos + 2 * suma_interior)
    
    return integral

# --- Bloque principal (Ejecución) ---
if __name__ == "__main__":
    limite_inf = 1.0
    limite_sup = 9.0
    segmentos = 4
    
    resultado = regla_trapecio_multiple(f, limite_inf, limite_sup, segmentos)
    
    print(f"--- Análisis Numérico ---")
    print(f"Límites de integración : [{limite_inf}, {limite_sup}]")
    print(f"Número de segmentos    : {segmentos}")
    print(f"Valor Aproximado (I)   : {resultado:.5f}")
